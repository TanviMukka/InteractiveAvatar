# Interactive Avatar
An interactive avatar built with p5.js which blinks and smiles when you click on it

### Live Demo
[View Live Project](https://tanvimukka.github.io/interactiveavatar/)

### Built With
* HTML5
* JavaScript (ES6)
* p5.js
* p5.sound
* p5play
* Planck.js
